# Third-Party Notices

This repository is published under a proprietary, source-available, **view-only** licence
(see [`LICENSE`](LICENSE)). The components listed below are **not** owned by Aile Robotics
and keep their own licences; nothing in `LICENSE` changes those terms.

Two categories are distinguished because they carry very different redistribution risk:

- **Bundled** — the component's bytes are committed to this repository, so publishing the
  repository redistributes it. Redistribution licence **must** be clean.
- **Referenced (not vendored)** — the component is imported or driven at run time but its code
  is **not** committed here; a user must install it separately. Publishing this repository does
  not redistribute it.

## 4. Copyleft / non-commercial conflict assessment

The task brief asks whether any **copyleft (GPL/AGPL/LGPL) or non-commercial** term conflicts
with a proprietary view-only publication, and exactly which files are affected.

- **No GPL/AGPL/LGPL source code is vendored** in this repository. Nothing committed here is a
  copyleft-covered file, so publishing the repository under the view-only licence does not
  violate any copyleft distribution term.
- **Blender is GPL**, but it is used only as an **external tool** driven via its `bpy` API; Blender's
  code is not shipped, and the generated `.blend`/USD/render **output is not a derivative work of
  Blender** (the GPL FAQ treats program output as not covered by the program's licence). **No
  conflict with any committed file.**
- **FFmpeg (LGPL/GPL)** reaches the project only through the `imageio-ffmpeg` pip package at run
  time; no FFmpeg binary is committed. **No conflict with any committed file.**
- **No non-commercial-only (e.g. CC-BY-NC) asset is bundled.** The bundled Poly Haven assets are
  CC0, which permits commercial and non-commercial redistribution alike.

> **Conflict verdict: NONE among committed files.** The only licence-text items that touch
> committed files are the two **Apache-2.0** first-party headers in §3 — permissive, not copyleft,
> and left for the owner to reconcile. No file blocks a clean view-only publication.
